# Commerce datasets

Git stores schemas, generation/validation reports and the 15-record review sample. Bulk JSONL files and dataset ZIP archives remain local; they are not included in application deployments. Some generated files exceed GitHub's single-file limit.

Use the generation, expansion and integration scripts under scripts/ and each dataset README for provenance. A report records a local run; its presence does not mean the corresponding bulk dataset is downloaded with this repository. Preserve the existing local datasets and checksums when reproducing experiments.
