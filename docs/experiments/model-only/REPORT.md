# 純模型判斷切換

依使用者要求，正式 Gateway 只以 XGBoost 分數及既有 0.84 門檻判定攻擊；規則命中只記錄、不觸發沙盒。模型無法推論時回傳 503 要求重試，不用規則替代。既有訪客的持續隔離與管理員解除流程保留。

模型未重新訓練、門檻未降低。218 筆診斷含 179 筆正常與 39 筆攻擊字串：正常誤報 0，攻擊命中 15、漏判 24。漏判包含所有僅放在非 content-type header 的測試（目前模型輸入不含這些 header）及部分 query/body。完整名單見 known-misses.json。這是已知回歸基準，不是盲測或安全保證；CI 會拒絕新的漏判、正常誤報或推論故障，既有漏判仍明確輸出。

原先 UNION SELECT 1 的部署樣本是規則命中但模型低分；驗收現在要求它留在 real，另用模型高分的 SQLi 樣本驗證沙盒切換。這是分流機制測試，不能宣稱所有 SQLi 均可偵測。

SOC 顯示來源 IP 及四位小數的模型百分比分數。來源由既有可信入口取得，未改用任意客戶端 header。IP 篩選針對已載入事件（最多 2,000 筆）；內部識別與解除操作仍以訪客為單位，避免 NAT 共用 IP 導致跨訪客隔離。舊紀錄保留原本判斷與路由，不回寫或偽裝為新策略。

保留 rules_enforce=True 僅供歷史規則診斷測試；Gateway 不啟用，也沒有可由請求開啟的選項。資料庫結構、append-only 保護、非同步提交、Mirage 與真實／沙盒網路隔離不變。
